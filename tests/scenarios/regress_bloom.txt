# Bloom headless (FINDINGS.md "Bloom", src/game/pc_bloom.cpp): PC Options' Bloom is the title's cl_hdrbloom, which
# each map's light config sets as the map starts ("exec <map>-light.cfg", 0.5 on de_aztec). Started with Bloom Off:
# the map's 0.5 is taken back to 0; On gives the map's 0.5 back; an intensity set in the console (0.3) stays through
# Off and On. The reference renderer's bloom, at aztec's white sky with the player held there (tools/drive.py
# setview, no bots): On adds its glow across the frame, not only in the top left corner (the last pass kept the
# scissor of the small targets before SDK patch 0034), and the setting is saved. (Auto Exposure off, so the frames
# compare directly; the snaps follow a change of setting, as Auto Exposure Off chosen before the start is only
# in force from the first change: TODO.md.)
#   --env FPS=30 --pc bloom=0 --pc auto_exposure=0 --launch tests/launch/de_aztec_nobots

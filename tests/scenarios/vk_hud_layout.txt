# HUD layout (N10, src/game/pc_hud_layout.cpp, docs/n10_hud.md): in a match on de_dust2 (no bots), window shots of
# the HUD as the title draws it; then a saved layout (the money 100 units left and 60 up at 1.5 times its size, the
# radar at 0.75, HUD Scale 115%) moves and resizes them (shots); the editor (F7, pc_hud_edit) opens, Tab chooses the
# next element, the arrows move it, + grows it, Enter saves: the layout is written to the settings.
# Run with tools/run_window_tests.py (gamescope --backend headless -W 1280 -H 960), with
#   --launch tests/launch/de_dust2_nobots
# timeout: 300
wait log open D:\\de_dust2.sxwad
sleep 25
key Down
sleep 3
key Down
sleep 3
key Space
sleep 10
closebuymenu
sleep 2
closebuymenu
sleep 2
windowshot hud_original
pckey set hud.money -100 -60 1.5
pckey set hud.radar 0 0 0.75
pckey set hud_scale 115
sleep 2
windowshot hud_moved
pckey set hud_scale 100
pckey cmd pc_hud_edit
wait log pc hud: the HUD editor opened \(full screen layout\)
sleep 1
key Tab
sleep 0.5
key Left
sleep 0.3
key Left
sleep 0.3
key Up
sleep 0.3
key =
sleep 1
windowshot hud_editing
key Return
wait log pc hud: the layout saved \(full screen\)
expect setting hud.armor -4 -2 1.05
sleep 1
windowshot hud_saved
expect nolog Host_Error

# A Single Player match with no bots: each player picks the Terrorists with its own controller (d-pad and A; the
# team limit off: all carry the Glock, whose rounds the state counts), closes its
# buy menu (B). Then rounds of actions: in each, every player does a different one (move: left stick; aim: right
# stick; shoot: right trigger; weapon: Y, the next weapon, twice, the keyboard 3 then 2 and the mouse for player 1);
# each player's own state (its process, @N steps) shows its action and nothing of the others'. Over the rounds every
# player does every action. Each player's scoreboard (Back) and pause menu (START) are its own.
# Generated (the N4.6 controller scenarios); run with tools/run_window_tests.py (gamescope --backend headless
# -W 1920 -H 1080), with
#   --env CSX_SPLIT_COMPOSITOR=1 --env CSX_SPLIT_PLAYERS=4 --env CSX_SPLIT_ZCACHE=$PWD/build/zcache

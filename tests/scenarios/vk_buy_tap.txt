# The buy menu's tap in the Vulkan window (FINDINGS.md "Buy menu taps", regress_buy_tap.txt headless): the title
# opens the buy menu on +buymenu's release only when it was held 0.05 to 0.5 s of real time; drive.py's `pckey tap`
# has the game hold it on its own clock, pressed right after the HUD's half-second settings check. The buy time set
# to 60 minutes first, as the other window buy tests (without it the window run's buy was refused about 50 s after
# its spawn, where headless buys at 40 to 90 s; not traced). At 30, 60, 120 and 240 frames per second, VSync off
# (the Frame Rate Limit changed while playing): taps of 0.08 and 0.35 s open the buy menu (the right button closes
# it), a hold of 0.7 s does not.
# Run with tools/run_window_tests.py (gamescope --backend headless -W 1280 -H 960 -r 240), with

# Gun Game (N6D, src/game/pc_modes.cpp, docs/n6_modes.md), headless: de_aztec, 7 bots, rounds of 1 minute and
# "+pc_gamemode gungame". Kills move players up the ladder (reaches level lines, the weapons given), the dead spawn
# again, no round ends past the round's minute. Then the ladder set on the server's console (pc_gungame_order deagle
# awp: the knife added last) is taken, and an unknown name refuses it.

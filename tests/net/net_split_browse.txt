# Split-screen through the server browser (docs/splitscreen.md): one PC's compositor, two local players; player 1
# opens Multiplayer's LAN list in the menus (keyboard), picks Bravo (a dedicated server with a password), types the
# password on the keyboard screen and joins (the title relaunches into the server, its key pinned); the compositor

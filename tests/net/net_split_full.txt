# Split-screen against a full server (docs/splitscreen.md 12): csx-server with 3 player slots and 2 bots. One PC's
# compositor with two local players joins: player 1 takes the last slot, player 2 is refused ("The server is full."):
# the refusal reaches the compositor, player 2 keeps its place in the layout (START on its controller tries again).
# A second controller's START adds a third local player: refused too, it gives its slot back (two local players
# again, its controller free). Nothing else ends: player 1 picks its team (Space) and plays on: the server has 3
# clients (player 1, 2 bots). The split side stays until the server has counted (its script ends ~20 s in; a client
# gone for 15 s times out, so the count 60 s after the first refusal needs player 1 still there).
# timeout: 600
[server] --server "--map de_aztec --bots 2 --max-players 3" --env CSX_LOG_NET=1
wait log net:.server.identity
count net:.client.127\.0\.0\.[12]:[0-9]+.connected 1
wait log refused:.Server.is.full
sleep 60
players three
expect playercount three 3 3
pckey cmd quit
[split] --window 1920x1080 --after server:net:.server.identity --delay 3 --launch tests/launch/connect_local --env CSX_SPLIT_COMPOSITOR=1 --env CSX_SPLIT_PLAYERS=2 --env CSX_SPLIT_ZCACHE=$PWD/build/zcache --env CSX_LOG_NET=1
wait log split: player 1 started
pad 1 attach
pad 2 attach
wait log p1: net: server 127.0.0.1:27015 connected
wait log p1: pc keys: menu TeamSelect
sleep 4
key Space
wait log split: player 2 started
wait log split: player 2's match ended: refused The server is full\.
wait log split: player 2 was refused by the server: START on its controller tries again
wait log split: player 2's process ended
sleep 3
pad 2 button start
wait log split: a controller's START: 3 local players
wait log split: player 3's match ended: refused The server is full\.
wait log split: player 3 was refused by the server: its slot given back \(2 local players\)
sleep 3
windowshot after
expect nolog split: player 1's process ended
expect log p1: pc keys: menu TeamSelect
expect nolog guest trap
sleep 70
